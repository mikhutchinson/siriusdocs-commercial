# SiriusDocs 0.1.0

First commercial binary Swift/Python document-ingestion SDK. Includes PDF,
DOC/DOCX, XLS/XLSX, PPT/PPTX, ODT/ODS/ODP, EPUB, HTML, RTF, CSV, Markdown and
text. AsciiDoc and LaTeX preserve source with explicit warnings.

Native/Swift binaries target macOS 26 arm64. Compiled CPython 3.10–3.14 core
wheels retain independent non-Apple imports; native DOC/RTF require macOS.
SwiftPython is pinned to 0.7.0 under its supplied license.

Results include ordered units, structural Markdown, local assets, limits,
warnings and provenance. Existing SiriusPDF API names remain available.
General layout fidelity, arbitrary legacy Office drawings, full Word semantics,
formula OCR and handwriting remain limited. AsciiDoc/LaTeX semantic conversion,
mobile/App Store qualification and optional model bundles are not included.
